# Guide d'installation — StuGo CO2 Explorer v6.1

---

## Avant de commencer

**Configuration requise**
- Windows 10 ou Windows 11 (64 bits)
- Aucun droit administrateur requis
- Environ 500 Mo d'espace disque disponible

**Fichier nécessaire**
- `StuGoCO2_Setup_v6.1.exe` — fourni par votre responsable ou disponible sur le réseau partagé

---

## Étape 1 — Lancer l'installeur

Double-cliquez sur le fichier `StuGoCO2_Setup_v6.1.exe`.

> Si Windows affiche un avertissement « Éditeur inconnu », cliquez sur **Exécuter quand même**.
> Ce message apparaît pour tout logiciel non signé par un certificat commercial — il n'indique pas un danger.

---

## Étape 2 — Choisir la langue

Une fenêtre vous demande de choisir la langue d'installation.

- Sélectionnez **Français**
- Cliquez sur **OK**

---

## Étape 3 — Lire les informations

L'écran suivant affiche les informations d'installation :
- Ce qui sera installé
- L'emplacement des fichiers du programme
- L'emplacement de vos données personnelles

Lisez ces informations, puis cliquez sur **Suivant**.

---

## Étape 4 — Choisir le dossier d'installation

Le dossier d'installation est pré-rempli automatiquement :

```
C:\Users\<votre nom>\AppData\Local\Programs\StuGo CO2 Explorer\
```

> **Recommandation :** conservez ce dossier tel quel et cliquez sur **Suivant**.

---

## Étape 5 — Créer les raccourcis (optionnel)

Vous pouvez cocher une ou plusieurs options :

| Option | Description |
|--------|-------------|
| Raccourci sur le Bureau | Crée une icône StuGo CO2 Explorer sur votre Bureau |
| Raccourci Admin Logs | Crée une icône pour l'outil de journaux |

Faites votre choix, puis cliquez sur **Suivant**.

---

## Étape 6 — Prêt à installer

Un résumé s'affiche avec les choix effectués.

Cliquez sur **Installer** pour démarrer l'installation.

---

## Étape 7 — Installation en cours

Une barre de progression indique l'avancement de l'installation.
Cette étape dure environ **1 à 3 minutes** selon votre ordinateur.

> Ne fermez pas la fenêtre pendant cette étape.

---

## Étape 8 — Fin de l'installation

L'installation est terminée. Vous avez la possibilité de :

- ☑ **Lancer StuGo CO2 Explorer maintenant** *(coché par défaut)*

Cliquez sur **Terminer**.

---

## Premier lancement

Au **premier démarrage**, l'application prend quelques secondes supplémentaires
(extraction interne des composants). C'est normal — les démarrages suivants seront plus rapides.

L'écran de chargement apparaît, puis la fenêtre principale s'ouvre.

---

## Où sont stockées vos données ?

Vos fichiers personnels (sessions, préférences, presets de couleurs, journaux)
sont enregistrés automatiquement dans :

```
C:\Users\<votre nom>\AppData\Local\StuGoCO2\
```

Pour y accéder rapidement :
1. Appuyez sur les touches **Windows + R**
2. Tapez `%LOCALAPPDATA%\StuGoCO2`
3. Appuyez sur **Entrée**

> Ces données ne sont **pas supprimées** lors d'une mise à jour du logiciel.

---

## Désinstallation

Pour désinstaller le logiciel :

1. Ouvrez le **Menu Démarrer**
2. Recherchez **StuGo CO2 Explorer**
3. Dans le groupe du programme, cliquez sur **Désinstaller StuGo CO2 Explorer**

Ou bien :
1. Ouvrez **Paramètres Windows → Applications**
2. Recherchez **StuGo CO2 Explorer**
3. Cliquez sur **Désinstaller**

À la fin de la désinstallation, une fenêtre vous demandera si vous souhaitez
**supprimer vos données personnelles** (sessions, presets, logs).
Répondez **Oui** pour une suppression complète, ou **Non** pour les conserver.

---

## Problèmes courants

| Problème | Solution |
|----------|----------|
| L'application ne démarre pas | Attendez 10 secondes au premier lancement (extraction interne) |
| L'icône n'apparaît pas sur le Bureau | Recochez l'option raccourci lors de la réinstallation |
| Message « Éditeur inconnu » | Cliquez sur **Exécuter quand même** — c'est normal |
| Erreur à l'import d'un fichier Excel | Vérifiez que le fichier est au format StuGo CO2 Explorer (voir onglet Aide dans l'application) |
